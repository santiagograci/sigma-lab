# 🛡️ Proyecto Sigma-Lab: Cloud-Native & DevSecOps Architecture

Laboratorio práctico de nivel de producción en Microsoft Azure enfocado en arquitectura Zero-Trust, contenedores y observabilidad empresarial.

## Stack Tecnológico
- **Cloud & IaC:** Azure (VNET, AKS, ACR, Key Vault, Service Bus, Storage), Bicep, Azure RBAC.
- **CI/CD Dual:** GitHub Actions & Azure Pipelines.
- **DevSecOps:** Snyk (SAST, SCA, Container Scanning) & Managed Identities (Passwordless).
- **Observabilidad:** Azure Monitor, Application Insights & Splunk.
